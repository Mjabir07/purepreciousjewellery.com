# Pure Precious Jewellery L.L.C

Informational website (no online store) for Pure Precious Jewellery, Gold Souq, Deira, Dubai.

- Static HTML/CSS/JS, no framework. Preview with any static server, e.g. `python3 -m http.server`.
- 3D animated home hero: `assets/js/hero3d.js` (Three.js, vendored in `assets/vendor/`).
- Pages are generated by `tools/build_pages.py` from `products.json` — edit those, not the `.html` files, then run `python3 tools/build_pages.py`.

## Product photos

Photos live in one folder per category:

```
assets/img/products/
  rings/
  necklaces-pendants/
  bracelets/
  earrings/
```

Use lowercase names with dashes, e.g. `gold-solitaire-ring.jpg`. Each photo needs a `.jpg` and a `.webp`
(around 1200×1200 px). Then add an entry to `products.json` under its category:

```json
{ "name": "Gold Solitaire Ring", "detail": "18K yellow gold",
  "images": ["assets/img/products/rings/gold-solitaire-ring", "assets/img/products/rings/gold-solitaire-ring-worn"],
  "focus": "50% 70%" }
```

- `images`: paths without extension; the first is the card photo, the rest appear as a gallery when the piece is opened.
- `focus` (optional): which part of a tall photo to keep in the square card (`"50% 70%"` = centre, lower down).
- `video` (optional): path without extension to `assets/video/<name>.mp4` plus `<name>-poster.jpg`; plays on the home page category tile.

The first product in each category is shown on the home page tile.
