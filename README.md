# Pure Precious Jewellery L.L.C

Informational website (no online store) for Pure Precious Jewellery, Gold Souq, Deira, Dubai.

- Static HTML/CSS/JS — no build step. Open `index.html` through any static server (e.g. `python3 -m http.server`).
- 3D animated home hero: `assets/js/hero3d.js` (Three.js, vendored in `assets/vendor/`).
- Pages: `index.html`, `collections.html`, `custom-design.html`, `about.html`, `contact.html`.
- Product photos: replace the placeholder icon inside each `.product-media` block in `collections.html` with `<img src="assets/img/products/..." alt="...">`.
- Contact details are in the footer/contact blocks of each page and in `assets/js/main.js` (WhatsApp / email for the enquiry form).
